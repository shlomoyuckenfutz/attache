Prior 5m-resampled 4H baseline was held ≈ −$5 / PF ≈1.0 — HTF native bars flipped the ranking.

Drawing rules

  1. Start highest TF; up-lines = higher lows; down-lines = lower highs.
  2. Drop TF only when a steeper valid line appears.
  3. Invalid if price already intersected — redraw from last clean structure.
  4. Prefer ≥2–3 clean touches; ~week+ of 4H data when possible.
  5. Action line = break/bounce object; Safety line = opposing risk/trail.

Setups

  • Bounce: action = safety = same line; enter on test; close-through = exit.
  • Break (2-touch): enter only if safety nearby (tight risk); else skip.
  • Break (3-touch+): same mechanics; higher respect when well tested.
  • Trail: BE → profit behind evolving safety; exit on close through safety.
[ ] Top-down done (M→W→D→exec TF); lines do not intersect history [ ] Point A / Point B clean; ≥2–3 touches where possible [ ] Setup: Bounce / 2-touch break / 3-touch break [ ] Action + safety identified (or waiting for swing) [ ] Risk to safety acceptable; size to that distance [ ] Entry only on break/bounce — not mid-air [ ] Trail: BE → profit behind safety; exit on close through safety

Rule card

  2. Clock: ready ~9:25 ET; trade open impulse; typical hold 10–20m.

  9. Max ~2/day; two losers → done.

CAVEATS

  1. Proxy data: SPY/QQQ/DIA ≠ ES/NQ/YM (beta, hours, tick size, overnight liquidity differ).
  2. IEX ≠ SIP: single-exchange prints; gaps and thin premarket levels. ONH/ONL are equity premarket proxies, not true Globex overnight.
  3. Mechanical approximation: discretionary markup (DOLs, trendlines, S/R) will differ from fractal/tolerance encodings.
  4. No news filter on these runs.
  5. Breakout v2 edge (if any) is small open-drive scalps with BE/trail — full 1:4 targets are rare; QQQ carries held-out gains.
  6. Trendline HTF looks strongest on held-out dollars, but still a mechanical simplification of discretionary line work.
  7. Not ready for live size from this study alone. Promote bar remains separate (tagged forward test with go-ahead).
